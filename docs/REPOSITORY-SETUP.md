Repository: https://github.com/grismosw79/dri-plus-3

Owner: `grismosw79`. Visibility: private. The initial source import is based on the November 19 T3 release.

Email privacy is enabled for the owner account. Web commits use the account's GitHub-provided noreply address. For local commits, configure this repository with the DRI alias and the exact noreply address shown in that account's GitHub email settings before the first push.

Keep the current source as the release baseline, with investigation and fix branches reviewed through pull requests. Build outputs, the original full release archive, user saves and captured game memory do not belong in this repository.

Get the exact GitHub usernames from Ace, Zip and Sdmart3 before inviting them. Discord names alone do not identify GitHub accounts. Collaborators have not yet been invited. Branch protection and reviewer settings have not yet been configured.

The browser session used for the initial import is signed in as the repository owner. Other development tools must also authenticate as the intended DRI identity before pushing; creating this repository does not switch unrelated connected accounts.
